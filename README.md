# Crystal Volume Booster v1.6 – Device Sound Hub

New top-level Device Media Volume control uses Android AudioManager on the shared STREAM_MUSIC channel. It changes the **normal volume** for most media apps, up to the **phone's existing limit**. The UI displays device volume, synchronized with hardware volume key changes while open. Dedicated +/− controls adjust one step at a time.

The Phone Sound Settings shortcut opens your device's OEM audio features, such as an equalizer or Dolby, if supplied by the manufacturer. Availability depends on device. No guarantee of system-wide amplification above the hardware limit.

Local file player still supports its own signal boost, equalizer, extra loudness, and limiter where supported. That local DSP does not process audio from YouTube, Instagram, Spotify or calls.

Download a signed debug APK from GitHub Actions artifact `CrystalVolumeBooster-v1.6-APK`. Keep listening at a comfortable level.
